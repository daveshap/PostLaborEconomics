# Research

The research reports, as PDFs (103). Browse them by theme on the website: [Research library](https://daveshap.github.io/PostLaborEconomics/research/).

Plain-text copies are in [`Research_txt/`](../Research_txt/). To put new reports on the website, run `generate_pdf_pages.py`; to make their text copies, run `convert_pdfs_to_txt.py`.
